# Family Hub on phones

An installable web app (iPhone and Android) that works alongside the Family Hub app on the family PC.
It shows the family's school records, calendar, messages, goals, library and diaries.

The family's data is not in this repository. It is kept in the family's own private cloud,
encrypted on the family's devices before it leaves them. A phone can read it only after it has
joined the family with a code from the PC and a parent has unlocked it with their password.
This repository holds only the app's code.
