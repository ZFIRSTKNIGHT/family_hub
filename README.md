# Family Hub on phones

An installable web app (iPhone and Android) that works alongside the Family Hub app on the family PC.
It shows the family's school records, calendar, messages, goals, library and diaries.

The family's data is not in this repository. It stays in the family's OneDrive, encrypted;
a phone can read it only after a parent unlocks it with their password. This repository
holds only the app's code.
